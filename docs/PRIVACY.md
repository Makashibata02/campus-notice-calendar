# 数据与外部服务

- 数据和导入文件保存在本机Electron userData目录，通常是 `%APPDATA%/campus-calendar`，与安装目录分开。
- 识别时发送用户选中的材料和必要上下文至配置的DeepSeek服务，不上传整个资料库。用户应自行检查待上传内容。
- 读取网页会访问原网站；配置Key时可能先请求DeepSeek网页读取接口，随后按需要本机渲染页面和读取图片。网站及模型服务可接收相应请求。
- 邮件通过用户设置的SMTP服务投递，标题与正文包含事项内容；服务接收不保证进入收件箱。
- Key和邮箱授权码由主进程保管。Windows safeStorage不可用时只在本次运行内存保留。界面只获得已配置状态，不直接获得密钥。
- 常规备份不包含凭据。跨电脑恢复后需重新配置，恢复后默认暂停提醒供检查；卸载默认保留资料，设置中可清理。

本仓库不提供公共服务器、多人账号或遥测后台。不要在Issue、截图、日志或提交中上传真实Key、邮箱授权码及私人通知。
